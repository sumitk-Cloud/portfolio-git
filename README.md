## Local preview
Open `index.html` in a browser.

## GitHub Pages
1. Create a repository and upload all files.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/root`.
5. Save.

## AWS S3 + GitHub Actions
This static site is also suitable for an S3 deployment workflow. Your GitHub Actions project can sync the site to S3 after each push to `main`.
